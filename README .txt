# 📚 Study Planner

A clean, user-friendly study planner built with plain **HTML, CSS, and JavaScript** — no frameworks, no installations needed. Just open and use!

---

## ✨ Features

- 📝 **To-Do List** — Add study tasks with due dates and priority levels (High / Medium / Low)
- ✅ **Mark tasks as done** — Check off tasks as you complete them
- 🔍 **Filter tasks** — View All, Pending, or Completed tasks
- 🧠 **Topic Tracker** — Add topics and tag them as Weak 😰 or Strong 💪
- 🔄 **Move topics** — Promote a weak topic to strong as your confidence grows
- 💾 **Auto-save** — All your data is saved in the browser automatically (localStorage)
- ⌨️ **Keyboard friendly** — Press `Enter` to quickly add tasks or topics

## 📌 How to Use

### To-Do List

1. Type your task in the input box (e.g. _Revise Chapter 3 – Trigonometry_)
2. Optionally set a due date and priority level
3. Click **+ Add Task** or press `Enter`
4. Click the checkbox to mark a task as done
5. Use the filter buttons to view All / Pending / Completed tasks
6. Click **Clear Completed** to remove finished tasks

### Topic Tracker

1. Type a topic name (e.g. _Integration_, _Newton's Laws_)
2. Enter the subject name (e.g. _Maths_, _Physics_)
3. Select **Weak** or **Strong**
4. Click **+ Add Topic** or press `Enter`
5. Click **→ Strong** to move a weak topic once you've improved
6. Click **← Weak** to move it back if you need more practice
